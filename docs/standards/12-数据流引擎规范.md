# 数据流引擎规范

## 1. 数据包（DataPacket）设计

```typescript
export interface DataPacket {
  id: string;             // 唯一标识
  timestamp: number;      // 创建时间戳
  sourceNodeId: string;   // 来源节点
  triples: Triple[];      // 三元组数据
  metadata?: Record<string, unknown>;  // 附加元数据
}
```

## 2. 数据流方向

```
节点 A → DataPacket → 节点 B（通过画布上的连线传递）
                               ↓
                         DataFlowEngine（订阅节点变化，自动传播）
                               ↓
                         WorkerPool（WebWorker 中执行 AI 节点）
```

## 3. 文件命名

| 文件 | 说明 |
|------|------|
| `src/dataflow/data-packet.ts` | 数据包类型定义 |
| `src/dataflow/engine.ts` | 数据流引擎 |
| `src/dataflow/execute-ai-node.ts` | AI 节点执行 |
| `src/runtime/NodeWorker.ts` | Worker 运行时 |
| `src/runtime/WorkerPool.ts` | Worker 池 |
