# 快照与书架规范

## 1. 快照定义

快照（Snapshot）用于保存和恢复画布的完整状态，包括节点、边、面板数据和流程状态。快照数据存储在 `bookshelf-store.ts` 中，持久化到 localStorage。

**快照数据结构：**

```typescript
interface BookSnapshot {
  id: string;                    // 唯一标识
  name: string;                  // 书名
  timestamp: number;             // 保存时间戳
  canvas: {
    nodes: Node[];               // 所有节点（不限插件类型）
    edges: Edge[];               // 所有连线
    collapsedNodes: string[];    // 已收起的节点
  };
  panelData: Record<string, Record<string, unknown>>;  // 所有节点的面板表单数据
  flowState: {
    mode: EditorMode;
    currentStep: number;
    stepStatus: Record<TabId, SignalStatus>;
  };
}
```

## 2. 快照保存规则

- 保存时从各 store 同步读取最新状态（使用 `getState()`）
- 必须保存以下数据源：
  - `canvas-store`: nodes, edges, collapsedNodes
  - `panel-data-store`: 所有节点的面板数据
  - `world-editor-flow-store`: mode, currentStep, stepStatus
- 保存时弹出命名对话框，由用户输入书名
- 默认书名为 `作品_MM/DD HH:mm` 格式

## 3. 快照恢复规则

- 恢复时调用 `canvas-store.loadCanvas()` 恢复节点和边
- 逐条恢复 `panel-data-store` 中每个节点的数据
- 恢复 `world-editor-flow-store` 的 mode、currentStep 和 stepStatus
- 恢复后自动关闭书架面板

## 4. 书架 UI 规范

- 模态框尺寸：900x440px（标题栏 40px + 书架区域 300px + 详情栏 100px）
- 每排显示 7 本书，书本尺寸 70x110px
- 书本以竖条矩形展示，显示书名前两个字符
- 选中书本高亮边框 `#6a9fb5`
- 详情栏显示：书名、保存时间、节点数、连线数、流程进度

## 5. 快照更新规则（继存）

- `updateBook(id)` 方法用于用当前画布最新状态覆盖指定书的快照数据
- 更新逻辑与 `saveBook` 相同，但不创建新条目，而是更新已有条目的所有字段
- 更新后 `timestamp` 刷新为当前时间
- 如果 `selectedBookId` 为 null，调用方应提示用户「请先在书架中选中一本书」
- 更新成功后弹出居中提示窗口，显示「已缓存：{书名}」，用户点击确定关闭
- 如果未选中书或书已被删除，同样弹出提示窗口告知用户

## 6. 书架文件同步规范

书架支持将快照同步到本地文件夹，每本书存为一个独立的 `.book` 文件。

**文件格式：**
- 扩展名：`.book`
- 格式：JSON，包含完整的 `BookSnapshot` 数据
- 版本号：`BOOK_FILE_VERSION = 1`

**文件名规则：**
```
{书名}_{时间戳}.book
```
- 书名中的特殊字符 `<>:"/\|?*` 替换为 `_`
- 书名截取前 50 个字符
- 时间戳格式：`YYYY-MM-DD-HH-mm-ss`

**同步策略：**
- `syncBooksToFolder(books)`：将书架所有书写入文件夹，每本书一个 `.book` 文件
- 自动清理已删除书的旧 `.book` 文件
- 加载时扫描文件夹中所有 `.book` 文件

**文件服务层：**
- 文件读写统一在 `src/services/file-service.ts` 中
- 使用 File System Access API（`showDirectoryPicker`）
- 文件夹句柄缓存到模块级变量，权限标记存 localStorage
- 降级方案：File System Access API 不可用时使用下载/上传

**断开书库：**
- 断开书库时清空书架（`books: []`, `selectedBookId: null`）
- 不清除本地文件夹中的 `.book` 文件（用户手动管理）
