# UI 与主题规范

## 1. 弹出菜单（Dropdown Menu）

弹出菜单用于工具栏按钮的次级操作选择，如「书架」按钮点击后弹出「打开书架」「保存此书」选项。

**设计规范：**
- 弹出菜单位于触发按钮的正下方，左对齐
- 背景色使用 `#0d0d0d`（面板色），边框 `#1e1e1e`
- 圆角 8px，阴影 `rgba(0,0,0,0.4)`
- 每个菜单项高度 36px，内边距 `8px 16px`
- 菜单项悬停时背景变为 `#1a1a1a`
- 点击菜单项后菜单自动关闭
- 点击菜单外部区域或按 ESC 键关闭菜单

**组件结构：**

```tsx
// 弹出菜单状态由父组件管理
const [menuOpen, setMenuOpen] = useState(false);

// 菜单项定义
const menuItems = [
  { label: '打开书架', onClick: handleOpenBookshelf },
  { label: '保存此书', onClick: handleSaveBook },
];

// 渲染菜单
{menuOpen && (
  <div style={overlayStyle} onClick={() => setMenuOpen(false)}>
    <div style={menuStyle}>
      {menuItems.map((item) => (
        <div key={item.label} style={menuItemStyle} onClick={item.onClick}>
          {item.label}
        </div>
      ))}
    </div>
  </div>
)}
```

## 2. 模态框（Modal Dialog）

模态框用于展示需要用户交互的较大界面，如「书架」面板。

**设计规范：**
- 全屏半透明遮罩层，背景 `rgba(0,0,0,0.6)`
- 模态框居中显示，固定尺寸（如 900x400）
- 背景色 `#0d0d0d`，边框 `#1e1e1e`，圆角 12px
- 标题栏高度 40px，右侧有关闭按钮
- 内容区域分上下两层（或按需布局），通过 flex 排列
- 点击遮罩层或关闭按钮关闭模态框

**组件结构：**

```tsx
export default function XxxPanel({ isOpen, onClose }: Props) {
  if (!isOpen) return null;

  return (
    <div style={overlayStyle} onClick={onClose}>
      <div style={panelStyle} onClick={(e) => e.stopPropagation()}>
        {/* 标题栏 */}
        <div style={headerStyle}>
          <span style={titleStyle}>标题</span>
          <button onClick={onClose} style={closeBtnStyle}>✕</button>
        </div>
        {/* 内容区域 */}
        <div style={contentStyle}>
          {/* 上层 */}
          <div style={topSectionStyle}>...</div>
          {/* 分割线 */}
          <div style={dividerStyle} />
          {/* 下层 */}
          <div style={bottomSectionStyle}>...</div>
        </div>
      </div>
    </div>
  );
}
```

## 3. 命名规范

| 类型 | 文件命名 | 组件名 | 说明 |
|------|----------|--------|------|
| 弹出菜单 | 内联在父组件中 | 无独立文件 | 简单菜单不拆分为独立文件 |
| 模态框 | `XxxPanel.tsx` | `XxxPanel` | 复杂面板拆分为独立组件文件 |
