# 插件系统规范

## 1. 插件目录结构

```
plugins/<plugin-name>/
├── manifest.json        # 插件元数据（必选）
├── index.tsx            # 导出 PluginNodeDefinition（必选）
├── types.ts             # 插件内部类型（可选）
├── Panel.tsx            # 面板组件（可选，hidden: true 的插件必选）
└── pages/               # 配置页面组件（可选）
    ├── PageXxx.tsx
    └── ...
```

## 2. manifest.json 规范

```json
{
  "type": "kebab-case-plugin-type",     // 全局唯一，英文
  "label": "中文显示名称",               // 用户界面显示
  "category": "核心",                    // 分类：核心 | 工具 | ...
  "icon": "📋",                         // 节点图标
  "fixedId": "004",                     // 三位数字字符串，需在 FIXED_IDS.md 注册
  "description": "功能描述",
  "hidden": false,                      // true = 面板插件（不显示在侧边栏/画布）
  "panelSlot": "floating",              // 面板插槽（hidden: true 时必填）
  "inputs": [
    { "id": "trigger-in", "label": "触发", "dataType": "signal" }
  ],
  "outputs": [
    { "id": "trigger-out", "label": "输出", "dataType": "signal" }
  ],
  "defaultData": {}
}
```

## 3. fixedId 注册规则

- 参见 `src/plugins/FIXED_IDS.md`
- 范围：核心插件 001-049，自定义 050-999
- 新增前必须查表，不可重复

## 4. 插件实现规范

```typescript
export default {
  manifest,       // 从 manifest.json 导入
  component,      // 画布节点组件
  panel,          // 可选：配置面板组件
} satisfies PluginNodeDefinition;
```

## 5. 🔥 热插拔规范（Hard Rule）

所有插件必须遵循热插拔原则——**删除 `src/plugins/<name>` 目录后，项目必须能正常编译运行**。

### 5.1 禁止事项

| ❌ 禁止 | 原因 |
|---------|------|
| `import xxx from '@/plugins/xxx'` | 删除目录后编译器找不到文件 |
| `import xxx from 'plugins/xxx/store'` | 同上 |
| 在 `App.tsx` 等核心文件中硬编码引用插件组件 | 删除插件后编译报错 |
| 在 `LogPanel.tsx` 等组件中硬编码插件开关按钮 | 删除插件后编译报错 |
| 在插件 `types.ts` 中定义核心模块需要的常量 | 应迁移到 `src/constants/index.ts` |

### 5.2 正确做法

| ✅ 允许 | 说明 |
|---------|------|
| `import.meta.glob('/src/plugins/*/manifest.json')` | 自动扫描，不存在返回空数组 |
| `import.meta.glob('/src/plugins/*/Panel.tsx')` | 自动扫描面板组件 |
| `pluginRegistry.getPanelsBySlot('floating')` | 通过注册表查询动态渲染 |
| `pluginRegistry.getPanel(type)` | 获取指定类型插件面板 |
| `constants/index.ts` 中的共享常量 | 插件和核心代码统一引用 |

### 5.3 面板插件特别规则

- 必须设置 `manifest.json` 中 `hidden: true` 和 `panelSlot: "floating"`
- 必须提供 `index.tsx`（空占位默认导出）和 `Panel.tsx`（实际组件）
- 面板组件必须**自包含**：自己管理开关状态、开关按钮、UI 渲染
- 开关按钮必须使用 `position: fixed` 或 `position: absolute`，**不依赖任何外部组件的布局**

### 5.4 添加新插件的步骤

1. 在 `src/plugins/<name>/` 目录下创建文件
2. 在 `FIXED_IDS.md` 注册新 `fixedId`
3. 运行 `npx vite build` 确认编译通过
4. **删除该目录后再次运行 `npx vite build` 确认编译通过**（热插拔验证）

## 6. 文件命名

| 文件 | 说明 |
|------|------|
| `src/plugins/FIXED_IDS.md` | fixedId 注册表 |
| `src/plugin-system/plugin-types.ts` | 插件类型定义 |
| `src/plugin-system/plugin-loader.ts` | 插件加载器 |
| `src/plugin-system/plugin-registry.ts` | 插件注册表 |
| `src/plugin-system/plugin-sandbox.tsx` | 插件沙箱 |
| `src/constants/index.ts` | 全局常量（包括插件面板尺寸等） |
