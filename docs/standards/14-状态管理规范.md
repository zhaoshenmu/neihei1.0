# 状态管理规范

## 1. Store 列表

| Store 文件 | 职责 |
|-----------|------|
| `app-store.ts` | 应用全局状态 |
| `canvas-store.ts` | 画布节点/边状态 |
| `bookshelf-store.ts` | 书架快照状态 |
| `execution-store.ts` | 执行状态 |
| `log-store.ts` | 日志状态 |
| `prompt-store.ts` | 提示词状态 |
| `settings-store.ts` | 设置状态 |
| `undo-store.ts` | 撤销/重做状态 |
| `workflow-store.ts` | 工作流状态 |
| `world-editor-flow-store.ts` | 世界编辑器流程状态 |
| `panel-data-store.ts` | 面板数据状态 |
| `panel-lifecycle-store.ts` | 面板生命周期状态 |
| `sticky-panel-store.ts` | 粘性面板状态 |
| `api-settings-store.ts` | API 设置状态 |
| `api-connection-store.ts` | API 连接状态 |

## 2. 设计原则

- 每个 Store 独立职责，不互相依赖
- 跨 Store 引用使用 `useXxxStore.getState()` 方式
- 持久化使用 `zustand/middleware` 的 `persist`
- localStorage 键名统一 `neihei-` 前缀
