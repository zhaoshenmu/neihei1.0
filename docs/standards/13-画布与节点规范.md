# 画布与节点规范

## 1. 画布组件

画布基于 React Flow 实现，核心组件在 `src/canvas/` 目录下。

## 2. 节点渲染

节点渲染组件在 `src/nodes/` 目录下：

| 组件 | 说明 |
|------|------|
| `NodeRenderer.tsx` | 节点渲染器，根据插件类型渲染对应节点 |
| `NodePort.tsx` | 节点端口（输入/输出） |
| `NodeWrapper.tsx` | 节点外层容器（标题、样式等） |

## 3. 画布交互

| 文件 | 说明 |
|------|------|
| `Canvas.tsx` | 画布主组件 |
| `Canvas.handlers.ts` | 画布事件处理 |
| `CanvasControls.tsx` | 画布控制按钮 |
| `ContextMenu.tsx` | 右键菜单 |
| `QuickConnectMenu.tsx` | 快速连接菜单 |
| `FlowEdge.tsx` | 自定义连线 |
| `BezierEdge.tsx` | 贝塞尔曲线连线 |

## 4. 节点宽度规范

所有插件节点的画布渲染宽度，必须遵循统一标准，从 `src/constants/index.ts` 的 `PLUGIN_NODE_WIDTH` 常量引用。

### 4.1 宽度标准

| 类型 | 宽度值 | 常量名 | 适用场景 |
|------|--------|--------|---------|
| 标准 | 260px | `PLUGIN_NODE_WIDTH.STANDARD` | 多数插件节点（默认选择） |
| 紧凑 | 220px | `PLUGIN_NODE_WIDTH.COMPACT` | 内容较少的节点 |
| 宽体 | 300px | `PLUGIN_NODE_WIDTH.WIDE` | 内容较多的节点 |

**参考基准**：World Editor 节点（minWidth: 200, maxWidth: 300）的中值。

### 4.2 关键规则

| # | 规则 |
|---|------|
| 1 | 所有插件节点的 `minWidth` / `maxWidth` 必须从 `PLUGIN_NODE_WIDTH` 常量读取，**禁止在各插件中硬编码宽度值** |
| 2 | 新插件节点必须先选型（标准/紧凑/宽体），然后在 `index.tsx` 中引用对应常量 |
| 3 | 如有特殊需求需要自定义宽度，须在 PR 中说明理由，并确保不破坏整体视觉一致性 |

### 4.3 使用示例

```typescript
import { PLUGIN_NODE_WIDTH } from '@/constants';

// 标准宽度节点
<div style={{ minWidth: PLUGIN_NODE_WIDTH.STANDARD }}>
```

## 5. 插件悬浮面板宽度规范

所有插件节点的双击弹出悬浮面板宽度，必须遵循统一标准。

### 5.1 宽度标准

| 类型 | 宽度值 | 常量名 | 适用场景 |
|------|--------|--------|---------|
| 标准面板 | 400px | `PANEL_WIDTH` (from `@/constants`) | 多数插件面板（默认选择） |
| 窄面板 | 360px | 特殊场景 | 内容较少的面板 |
| 宽面板 | 480px | 特殊场景 | 内容较多的面板 |

**参考基准**：World Editor 面板宽度 400px（`PANEL_WIDTH` 常量）。

### 5.2 关键规则

| # | 规则 |
|---|------|
| 1 | 所有插件悬浮面板的宽度必须从 `@/constants` 的 `PANEL_WIDTH` 常量读取或以此为基准，**禁止硬编码** |
| 2 | 新插件面板必须明确选择基准宽度，若需偏离标准值须在面板顶部注释中说明理由 |
| 3 | 面板高度可按需设定，但最小高度不低于 300px，最大不超过 1200px |

### 5.3 使用示例

```typescript
import { PANEL_WIDTH } from '@/constants';

// 标准宽度面板
const PANEL_W = PANEL_WIDTH; // 400px
const PANEL_H = 400; // 高度按需设定
```

## 6. 面板交互规范

### 6.1 面板关闭规则

所有插件节点的双击弹出悬浮面板，**禁止自带 ✕ 关闭按钮和标题栏**。

| # | 规则 |
|---|------|
| 1 | 面板不自带 ✕ 关闭按钮和标题栏，统一通过右键菜单 `ContextMenu` 提供「关闭面板」选项 |
| 2 | 「关闭面板」菜单项使用 `danger: true`（红色 `#ff6b6b` 样式） |
| 3 | 面板关闭后，再次双击同一标签可重新打开 |

### 6.2 面板防重复规则

双击标签打开面板时，必须检查该标签是否已有面板打开。

| # | 规则 |
|---|------|
| 1 | `addPanel(tabId)` 方法内须检查 `panels.some(p => p.tabId === tabId)`，有则跳过 |
| 2 | 同一标签在同一节点内，最多只能有一个面板实例 |
| 3 | 不同标签可并行打开各自面板，互不影响 |

### 6.3 面板宽度必须引用常量

所有插件节点的 `FloatingContainer` 宽度必须从 `PLUGIN_NODE_WIDTH` / `PANEL_WIDTH` 常量引用，禁止在各插件代码中硬编码数字。
