# 🗺️ 实施路线图

## 总览

```
Phase 1: 内核核心       → 最小可用内核
Phase 2: 基础节点+连线   → 可搭建工作流
Phase 3: 输出插件系统    → 多格式输出
Phase 4: LLM集成        → AI生成能力
Phase 5: 工作流引擎      → 高级工作流模式
Phase 6: 记忆+幻觉完善   → 全功能内核
```

---

## Phase 1：内核核心（预估 2-3 天）

**目标**：实现内核的 TripleStore + 洋葱层管理 + 基础验证，可以在画布上放置内核节点并打开面板。

### 1.1 数据结构

| 文件 | 内容 |
|------|------|
| `src/kernel/kernel.types.ts` | Triple、Constraint、MemorySnapshot 等类型定义 |
| `src/kernel/kernel.store.ts` | 内核状态管理（TripleStore、约束列表、检测日志） |

### 1.2 引擎层

| 文件 | 内容 |
|------|------|
| `src/kernel/engines/MemoryEngine.ts` | 记忆检索（按相关性从洋葱层检索三元组） |
| `src/kernel/engines/ConstraintEngine.ts` | 约束注入（构建增强提示词） |
| `src/kernel/engines/ValidationEngine.ts` | 幻觉检测（三元组提取 + 冲突对比） |
| `src/kernel/layers/OnionLayerManager.ts` | 洋葱层管理（升降级规则） |
| `src/kernel/layers/MemoryConsolidator.ts` | 记忆压缩（降级策略 + 回溯快照） |
| `src/kernel/layers/ConflictDetector.ts` | 矛盾检测（对比 Layer 0-1） |

### 1.3 UI 层

| 文件 | 内容 |
|------|------|
| `src/kernel/KernelNode.tsx` | 画布上的内核节点组件（带引擎图标和状态灯） |
| `src/kernel/KernelPanel.tsx` | 双击打开的控制面板（6标签切换容器） |
| `src/kernel/tabs/MemoryTab.tsx` | 记忆层管理标签页 |
| `src/kernel/tabs/ConstraintsTab.tsx` | 约束管理标签页 |
| `src/kernel/tabs/DetectionTab.tsx` | 幻觉检测记录标签页 |
| `src/kernel/tabs/SettingsTab.tsx` | 内核设置标签页 |

### 1.4 测试

- [ ] 内核节点可以在画布上放置
- [ ] 双击打开面板，6个标签可切换
- [ ] 记忆层显示4层结构
- [ ] 约束列表可编辑
- [ ] 检测日志可记录

| `src/nodes/EditNode.tsx` | 编辑节点（修改指令输入 + 时机选择） |
| `src/nodes/OutputNode.tsx` | 输出节点（插件选择下拉 + 预览区域） |
| `src/nodes/PluginNode.tsx` | 插件节点（从 chajian/ 动态加载） |
| `src/nodes/NodePort.tsx` | 增强：颜色编码端口（白/金/蓝/红/绿） |

### 2.2 连线系统

| 文件 | 内容 |
|------|------|
| `src/canvas/Canvas.tsx` | 增强：连线限制（同色相连 + 不支持提示） |
| `src/canvas/Canvas.handlers.ts` | 增强：端口拖拽连接事件 |
| `src/dataflow/` | 数据包在节点间传递的管道 |

### 2.3 测试

- [ ] 6种节点都可以从侧边栏拖入画布
- [ ] 端口颜色正确显示

## 技术债务考虑

| 项目 | 建议 |
|------|------|
| **状态管理** | 使用 Zustand（与现有 canvas-store 一致） |
| **UI 组件** | 使用现有 NodeWrapper 风格，保持一致 |
| **画布优化** | 避免 Phase 1-2 引入性能问题，Phase 5 再优化 |
| **数据持久化** | Phase 1 用 localStorage，Phase 6 再考虑 IndexedDB |
| **测试** | 每个 Phase 末尾做基本功能测试 |
